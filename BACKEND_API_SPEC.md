# Car Rental Application - Backend API Specification

This document provides a summary of the backend API for building a matching frontend.

## 🚀 Tech Stack
- **Framework**: Spring Boot 2.7.18
- **Authentication**: JWT (JSON Web Token)
- **Base URL**: `http://localhost:8080/api`
- **Content-Type**: `application/json`

---

## 🔐 Authentication & Authorization

### Login (JWT Generation)
- **URL**: `/api/auth/login`
- **Method**: `POST`
- **Request Body**:
  ```json
  {
    "username": "your_username",
    "password": "your_password"
  }
  ```
- **Success Response**: Returns a `access_token`.
- **Note**: This token must be included in the `Authorization` header as `Bearer <token>` for all secured requests.

### Registration
- **URL**: `/api/auth/registration`
- **Method**: `POST`
- **Request Body**: `UserInDto` (Username, Password, FirstName, LastName, Email).

## 🏎️ Car Management (`/api/cars`)

| Endpoint | Method | Role | Description |
| :--- | :--- | :--- | :--- |
| `/api/cars` | `GET` | Authenticated | List all cars (supports `page` and `sort` params) |
| `/api/cars/available` | `GET` | Authenticated | List only available cars |
| `/api/cars/{id}` | `GET` | Authenticated | Get car details |
| `/api/cars` | `POST` | `ADMIN`, `MANAGER` | Add a new car |
| `/api/cars/{id}` | `PUT` | `ADMIN`, `MANAGER` | Edit car details |
| `/api/cars/{id}` | `DELETE` | `ADMIN` | Remove a car |
| `/api/cars/packages` | `GET` | Authenticated | List available car rental packages |

## 🛠️ Security Roles
- **ROLE_USER**: Standard customer (Can browse cars, order, pay).
- **ROLE_MANAGER**: Can manage car inventory and view users.
- **ROLE_ADMIN**: Full access (Manage roles, delete data).
